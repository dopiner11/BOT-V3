# 🎛️ لوحة تحكم X.IRAQ FAMILY — Control Panel

لوحة تحكم ويب عربية (RTL) كاملة لإدارة بوت عائلة X.IRAQ من المتصفح.

## المميزات

- **🤖 التحكم بالبوت** — تشغيل / إيقاف / إعادة تشغيل + سجل حي مباشر، من خلال تشغيل البوت كعملية مستقلة (fork).
- **🔐 تسجيل دخول ديسكورد (OAuth2)** — يدخل فقط من له رتبة محددة في الإعدادات، وكل رتبة لها صلاحياتها.
- **👥 إدارة الأعضاء** — عرض الأعضاء ونقاطهم وحالتهم.
- **⚙️ محرر ملف الإعدادات** — تعديل `config.json` الرئيسي من المتصفح.
- **# الرومات والقنوات** — عرض كل الرومات المستخدمة في الإعدادات.
- **🎭 الرولات** — عرض كل الرولات.
- **🎫 التذاكر** — عرض التذاكر المفتوحة والمغلقة.
- **🏴 البلاك ماركت** — البائعون والطلبات والمنتجات.
- **📊 إحصائيات حية** — عدد الأعضاء، النقاط، التذاكر، الأنذارات، إلخ.
- **🛠️ إعدادات الموقع** — ضبط صلاحيات كل رتبة وخادم الموقع والمظهر.

## 🚀 التشغيل

```bash
# تثبيت الاعتماديات (مرة واحدة)
npm install --prefix dashboard

# تشغيل اللوحة
npm run dashboard
```

ثم افتح: `http://localhost:3000`

## ⚙️ الإعدادات — `dashboard/config.json`

كل شيء قابل للضبط من هذا الملف:

| المفتاح | الوصف |
|---|---|
| `server.host` | العنوان الذي يستمع عليه الخادم (0.0.0.0 = كل العناوين) |
| `server.port` | المنفذ |
| `server.sessionSecret` | سر تشفير الجلسات — **غيّره** لسلسلة عشوائية |
| `discord.clientId` | Client ID من لوحة مطوري ديسكورد |
| `discord.clientSecret` | **Client Secret** — ضعه هنا |
| `discord.redirectUri` | رابط الإعادة — يجب مطابقته تماماً لما في لوحة المطورين |
| `discord.guildId` | آيدي السيرفر |
| `permissions.roles` | قائمة الرتب → الصلاحيات (نظام RBAC) |
| `permissions.defaultDeniedMessage` | رسالة الرفض |
| `ui.*` | المظهر والبراند |

## 🔐 ترتيب تسجيل الدخول ديسكورد (خطوة خطوة)

1. افتح [لوحة مطوري ديسكورد](https://discord.com/developers/applications).
2. اختر تطبيقك (أو أنشئ جديد).
3. قسم **OAuth2 → General**:
   - اضف إلى **Redirects**: `http://localhost:3000/oauth/discord/callback`
   - انسخ **Client ID** و **Client Secret**.
4. ضعها في `dashboard/config.json` → `discord.clientId` و `discord.clientSecret`.
5. تأكد أن `redirectUri` في config يطابق تماماً ما أضفته لتوي.
6. شغّل اللوحة وجرّب `/login`.

> **ملاحظة النشر (استضافة)**: عند رفعك للسيرفر، استبدل `redirectUri` بعنوان موقعك الحقيقي، وأضِف عنوانك في لوحة المطورين. يُنصح بوضع `clientSecret` و `sessionSecret` في متغيرات بيئة بدل الملف.

## 🛡️ نظام الصلاحيات (RBAC)

- عند تسجيل الدخول، تُقرأ رتب العضو من ديسكورد.
- تُقارن مع `permissions.roles` في `dashboard/config.json`.
- لكل رتبة قائمة صلاحيات (e.g. `bot.start`, `config.edit`, `*` للوصول الكامل).
- **من ليس له أي رتبة في القائمة → يُرفض دخوله** برسالة "ما عندك صلاحية".

يمكن إدارة الصلاحيات من صفحة **"إعدادات الموقع"** في اللوحة (لكن تحتاج صلاحية `*` أو `settings.edit`).

## 🗂️ الهيكل

```
dashboard/
├─ server.js              ← الخادم الرئيسي
├─ config.json            ← إعدادات اللوحة (الكل)
├─ package.json
├─ middleware/
│  ├─ auth.js             ← OAuth2 + صلاحيات
│  └─ rbac.js             ← فحص الصلاحيات
├─ routes/                ← API + صفحات
├─ services/
│  ├─ botController.js    ← تشغيل/إيقاف البوت (fork)
│  ├─ dbReader.js         ← قراءة .data/*.json
│  └─ dashboardConfig.js  ← تحميل/حفظ config الموقع
├─ public/css, js         ← التصميم
└─ views/                 ← واجهة EJS عربية
```

## ⚠️ ملاحظة الأمان

- بيانات البوت (token) في `config.json` موجودة أصلاً في المشروع. لا ترفع `dashboard/config.json` (بعد ضبط Client Secret) إلى مستودع عام.
- امنح صلاحية `settings.edit` فقط للثقات من الإدارة.
